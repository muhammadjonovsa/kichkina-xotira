# Romantik Musiqa

Bu papkaga romantik background musiqa faylini qo'ying.

## Fayl nomi
Aynan `romantic.mp3` bo'lishi kerak (`audio/romantic.mp3`).

## Talablar
- Format: MP3
- Davomiyligi: 2+ daqiqa (loop bo'ladi)
- Xarakter: yumshoq, romantik, instrumental
- Sayt faylni **18%** ovozda, fade-in bilan chaladi

## Royalty-free manbalar
- https://pixabay.com/music/ (bepul)
- https://freemusicarchive.org/ (bepul)
- https://www.bensound.com/ (bepul)

## Muhim
Musiqa fayli bo'lmasa ham sayt buzilmaydi — brauzer Web Audio API
bilan o'zi yumshoq pianino/pad fon musiqa chizadi. Ovoshni 🔊 tugmasidan
o'chirish/yoniq mumkin.
